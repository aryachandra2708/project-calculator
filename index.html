📘 Panduan Penggunaan Lengkap

  1. Input Data: Masukkan angka pertama dan kedua pada input kolom yang tersedia.
  2. Aksi Cepat: Gunakan tombol Tukar Nilai untuk menukar input atau Acak Angka untuk menguji dengan cepat.
  3. Operasi Dasar: Pilih tombol operasi Tambah (+), Kurang (-), Kali (×), atau Bagi (÷).
  4. Operasi Modifikasi: Tersedia operasi modulus (%) untuk sisa bagi dan perpangkatan (xʸ).
  5. Validasi Otomatis: Aplikasi memvalidasi jika input kosong atau pembagian/modulus dengan angka 0.
  6. Statistik & Analisis: Setiap kalkulasi sukses akan menambah total perhitungan serta menganalisis sifat hasil (Positif/Negatif/Nol serta Ganjil/Genap/Desimal).
  7. Riwayat Perhitungan: Catatan transaksi hitung otomatis tersimpan di bagian riwayat.
